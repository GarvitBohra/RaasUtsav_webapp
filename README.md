## 🌟 Key Features

- **📡 360° Live Maps Radar & Turn-by-Turn GPS Directions**:
  - Live radar visualizer with concentric 5 km, 10 km, and 15 km range rings.
  - Interactive ground blips across SG Highway, Sindhu Bhavan Road, Infocity, GIFT City, GMDC Ground, and Kudasan.
  - Direct 1-click launch to native Google Maps navigation app.
  - GPS "Near Me" proximity calculations in kilometers.
- **🎟️ Pass Reservation & Instant Delivery**:
  - General Lawn and VIP Stage Gazebo passes with valet parking add-ons.
  - Promo code discounts (e.g. `GARBA2025` for ₹250 off).
  - Instant encrypted RFID QR Pass generation with download & print capabilities.
- **📱 Direct BookMyShow & District App Integration**:
  - Dedicated comparison modal showing live prices, booking platforms, and exclusive perks.
  - Direct deep links to official BookMyShow and Zomato District app event pages.
- **🗓️ 9-Day Sacred Navratri Calendar Tracker**:
  - From Day 1 Pratipada (Haldi Yellow) to Day 9 Navami (Suvarna Gold) with tithi rituals, daily auspicious colors, and Maha Aarti countdowns.
- **🔍 Advanced Sorting & Filtering Deck**:
  - Sort by **Most Popular**, **Highest Rated**, **Price: Low to High**, **Price: High to Low**, and **Near Me (GPS)**.
  - Filter by parking type (Valet, Reserved, Free), setting (Natural Lawn, AC Dome, Heritage Club), and city zone.

## 🚀 Getting Started

### Prerequisites
- Node.js 18+ or Bun
- npm, yarn, or bun

### Installation

```bash
# Clone the repository
git clone https://github.com/GarvitBohra/RaasUtsav_webapp.git
cd RaasUtsav_webapp

# Install dependencies
npm install

# Start local development server
npm run dev
